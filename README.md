# Python Product Manager 🚀

A clean and efficient command-line application built with Python to manage product inventories. This project demonstrates core programming concepts, file handling, and error management suitable for junior-level development.

## ✨ Features
- **Add Products:** Save product names, prices, and quantities.
- **Data Persistence:** Automatically stores and reads data from a structured `products.txt` file.
- **Search System:** Quickly find any product by its name using case-insensitive search.
- **Error Handling:** Safe input validation to prevent crashes from invalid data types.

## 🛠️ Tech Stack & Concepts
- **Language:** Python 3
- **File I/O:** Using `with open()` for secure file operations.
- **Data Structures:** Dictionaries and lists for in-memory data tracking.
- **Robustness:** Integrated `try-except` blocks for proper error management.

## 💻 How to Run
1. Clone the repository.
2. Run the main file using:
   ```bash
   python main.py
   ```
